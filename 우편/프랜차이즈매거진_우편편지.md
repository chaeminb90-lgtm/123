**사장님께.**

저희는 **프랜차이즈 매거진**입니다.

본사 편이 아니라 점주 편에서, 공정거래위원회 가맹사업정보에 공시된 자료를
읽고 정리하는 일을 합니다.

정보공개서에 적힌 '평균 **매출액**'이 사장님 손에 실제로 남는 돈과
얼마나 다른지, 그 차이를 계산해서 알려드리는 게 저희 일입니다.

저는 **가맹본사를 직접 운영했던 사람**입니다.
본사가 무엇을 보여주고 무엇을 안 보여주는지 알기 때문에,
지금은 점주 편에서 씁니다.

---

### 왜 이 편지를 보냈는가

요즘 업종 변경 문의가 눈에 띄게 늘었습니다.

그런데 대부분 **"어디로 바꿀까"부터** 물으십니다. 순서가 틀렸습니다.

먼저 보셔야 할 것은 세 가지입니다.

```
① 지금 브랜드의 작년 폐점 수
② 바꾸려는 브랜드의 가맹점당 평균 매출액
③ 필수품목 구조 — 본사가 어디서 돈을 버는가
```

이 셋은 전부 공정위에 **공시돼 있습니다.** 그리고 저희가 무료로 뽑아 읽어드립니다.

---

### 이번에 준비한 것

**공정거래위원회·한국공정거래조정원이 '착한 프랜차이즈'로 선정한 본사들과
협의를 마쳤습니다.**

이 본사들과 함께 **업종 변경을 무료로** 도와드립니다.

```
▸ 사장님 부담 비용 : 0원
  (지원 범위는 계약 전 문서로 확인시켜 드립니다)

▸ 저희가 받는 것 : 업종 변경이 잘 끝난 뒤 인터뷰 한 번.
  그게 전부입니다.
```

저희는 매거진입니다. **돈이 아니라 사례가 필요합니다.**
사장님의 실제 전후 숫자가 다음 호 콘텐츠가 됩니다.

---

### 상담만 받으셔도 먼저 드리는 것

전화로 상담만 받으셔도, **계약 여부와 관계없이**

> **네이버 [ 플레이스 세팅 / 플레이스 상위노출 / 블로그 포스팅 ○건 ]
> 무료로 먼저 해드립니다.**

받으신 다음에 "아니다" 싶으면 거기서 끝내셔도 됩니다.
먼저 드리고 시작하는 게 저희 방식입니다.

## 3. 착한 프랜차이즈 확인이 안 될 경우 — 대체 문구

"이번에 준비한 것" 단락만 아래로 교체.

> **저희가 직접 정보공개서를 열람해 거른 본사들과 협의를 마쳤습니다.**
>
> 기준은 세 가지였습니다. 작년 폐점 수가 신규 개점 수보다 적을 것,
> 가맹점 평균 매출액을 공시할 것, 필수품목 마진을 서면으로 밝힐 것.
> 이 셋을 통과한 본사들과 함께 **업종 변경을 무료로** 도와드립니다.

## 4. A/B 테스트용 2안 — 헤드라인만 교체

| | 1안 (데이터형) | 2안 (사연형) |
|---|---|---|
| 첫 문장 | 저희는 프랜차이즈 매거진입니다. | 저는 가맹본사 대표였습니다. |
| 소제목 | 왜 이 편지를 보냈는가 | 제가 본사에 있을 때 안 보여준 것 |
| 코드 | A-001 ~ A-300 | B-001 ~ B-300 |
| QR | 1안 전용 링크 | 2안 전용 링크 |

## 5. 금지어 체크리스트

```
✗ 장사 안 되는 분께        → 자존심 건드려 즉시 폐기
✗ 매출 보장 / 월 ○○○만원  → 검증 불가, 즉시 의심
✗ 검증된 브랜드            → 형용사. 숫자로 대체
✗ 무료 업변 (조건 없이)    → 사기 문구로 읽힘. 범위 명시 필수
✗ 당신의 두 번째 본사      → 본사용 슬로건. 점주에게 쓰지 않음
```
