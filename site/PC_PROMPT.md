# PC Claude Code 작업 지시: 하복당 가맹 페이지를 아임웹에 넣기

아래 내용을 그대로 따라 아임웹에 새 가맹 페이지를 **숨김 상태로** 만든다.
**게시하기는 누르지 않는다.** 메인 페이지와 기존 메뉴는 바꾸지 않는다. 마지막에 사용자에게 미리보기 화면을 보여 주고 확인을 받는다.

## 지켜야 할 것

- Chrome에서 아임웹 관리자에 이미 로그인된 상태로 작업한다. 비밀번호를 묻거나 입력하지 않는다. 로그인이 풀려 있으면 멈추고 사용자에게 로그인을 부탁한다.
- 기존 공통 코드, 기존 메뉴, 기존 위젯은 지우지 않는다.
- 붙여 넣는 코드는 아래 파일 내용 **전체**를 한 글자도 바꾸지 않고 넣는다.
- 예상과 다른 화면이 나오면 추측해서 누르지 말고, 스크린샷과 함께 사용자에게 묻는다.

## 순서

1. **새 메뉴 만들기**
   디자인 모드 > 메뉴 관리 > 메뉴 추가. 이름 `가맹안내(새)`, 페이지 URL `franchise-new`.
   메뉴 설정에서 **메뉴 숨김**을 켠다. 메뉴 순서는 맨 아래에 둔다.

2. **공통 코드 넣기**
   관리자 > 환경설정 > SEO(검색엔진최적화) > 고급 설정 > **공통 코드 삽입**을 켠다.
   - Header Code: 이미 있는 코드는 두고, 그 아래 줄에 00-common-head.html 전체를 붙여 넣는다.
   - Footer Code: 이미 있는 코드는 두고, 그 아래 줄에 00-common-body.html 전체를 붙여 넣는다.
   - 저장한다.

3. **본문 넣기**
   `가맹안내(새)` 페이지에서 섹션을 추가한다. 섹션 빈 곳을 우클릭 > **섹션 설정**:
   - 가로 100% 확장(전체 너비) 켜기
   - 좌우 여백 0, 상하 여백 0
   - 그리드 간격 0

   그 섹션에 **코드 위젯**을 추가하고 01-main-widget.html 전체를 붙여 넣는다.
   코드 위젯 설정의 **애니메이션은 '없음'** 으로 둔다.
   디자인 모드 화면에서는 코드 위젯 내용이 안 보이는 것이 정상이다.

4. **문의 입력폼 넣기**
   본문 섹션 바로 아래에 섹션을 하나 더 추가한다. 섹션 배경색 `#FFF8F0`.
   **입력폼 위젯**을 넣고 다음처럼 설정한다.
   - 입력폼 이름: `하복당 가맹 1:1 미팅 신청`
   - 항목: 이름(필수), 연락처(필수), 희망 지역(선택형: 서울/경기/인천, 필수), 문의 내용(여러 줄)
   - 개인정보수집 동의 켜기. 안내 문구:
     `수집 목적: 가맹 상담 일정 안내 / 항목: 이름, 연락처, 희망 지역, 문의 내용 / 보유 기간: 상담 종료 후 ○개월 / 동의하지 않을 수 있으며, 동의하지 않으면 상담 신청을 할 수 없습니다.`
     보유 기간(○개월)은 사용자에게 물어 채운다.
   - 버튼 문구 `1:1 미팅 신청하기`, 가로 꽉 채움
   - 접수 알림: 이메일 알림 켜기

5. **미리보기로 확인하고 사용자에게 보여 주기**
   **미리보기**를 열어 PC 폭과 모바일 폭(390px 정도)에서 확인하고, 각각 스크린샷을 찍어 사용자에게 보여 준다.
   - 처음 들어올 때 주황 화면에서 과일이 돌다가 원형으로 사라짐 (같은 탭에서 두 번째부터는 안 나옴. 다시 보려면 새 탭이나 시크릿 창)
   - 히어로 제목, 사진 슬라이더, 아래 과일 이름 띠
   - 스크롤하면 화면이 멈춘 채 바뀌는 장면 4곳(소자본 창업, 신메뉴 포스터, 마케팅, 운영 구조)이 사이트 헤더에 가리지 않음
   - 메뉴 탭 전환, 숫자 카운트, 하단 상담 바, 맨 아래 입력폼

6. **멈추기**
   여기까지 하고 **게시하기는 누르지 않는다.** 사용자에게 스크린샷과 함께 "확인 후 게시하기를 누를지" 묻는다.

## 문제가 생기면

- 본문이 글자만 보이고 꾸밈이 없다: Header Code 저장 여부를 확인한다. Header Code 안의 `cdn.jsdelivr.net` 주소를 새 탭에서 열어 CSS 내용이 보이는지 확인한다.
- 움직임이 없고 모두 정지해 있다: Footer Code 저장 여부를 확인한다. 이 경우에도 내용은 모두 보이므로 페이지 자체는 쓸 수 있다.
- 화면이 멈추는 장면이 헤더 뒤에 가리거나 어긋난다: 코드 위젯의 애니메이션이 '없음'인지, 섹션 설정의 여백이 0인지 확인한다.
- 사진이 안 나온다: 저장소가 공개 상태인지 확인한다. 비공개면 이미지와 스타일을 불러올 수 없다.
