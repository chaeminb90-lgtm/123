# 하복당 가맹 페이지 (아임웹용)

요거트월드 가맹 사이트(yogurtworldfran.co.kr)의 구성과 스크롤 연출을 참고해 만든 하복당 가맹 모집 페이지입니다.
본문은 아임웹 **코드 위젯 1개**에, 공통 스타일과 스크립트는 **공통 코드 삽입**에 넣습니다.
문의 입력폼, 머리말(헤더), 바닥글은 아임웹 기본 기능을 그대로 씁니다.

## 폴더 구성

| 경로 | 내용 |
| --- | --- |
| `src/sections/*.html` | 섹션별 원본 HTML (22개, 파일 이름 순서가 페이지 순서). `{{IMG}}`는 빌드할 때 이미지 주소로 바뀝니다. |
| `src/hbd.css`, `src/hbd.js` | 공통 스타일·스크립트 원본. 모든 스타일은 `.hbd` 안에만 적용됩니다. |
| `img/` | 웹용으로 줄인 이미지 27장 |
| `dist/hbd.css`, `dist/hbd.js` | 배포용 스타일·스크립트 (jsDelivr로 불러옴) |
| `dist/imweb/00-common-head.html` | 공통 코드 **Header Code**에 붙여 넣을 코드 (글꼴, 스타일) |
| `dist/imweb/00-common-body.html` | 공통 코드 **Footer Code**에 붙여 넣을 코드 (GSAP, ScrollTrigger, 하복당 스크립트) |
| `dist/imweb/01-main-widget.html` | 코드 위젯에 붙여 넣을 페이지 본문 전체 |
| `PC_PROMPT.md` | 사용자 PC의 Claude Code에게 줄 아임웹 작업 지시문 |
| `build.py` | 위 파일들과 미리보기를 만드는 스크립트 |

## 페이지 구성과 움직임

로딩 화면(과일 8개가 로고 주위를 돎) → 히어로(사진 슬라이더) → 소자본 창업(화면 고정, 사진 줌) → 운영 데이터(도넛 그래프) → 매입 구조 비교 → 박스당 1,000원 → 지점 이야기 → 지점별 손익표 → 공개된 지점 실적 → 문의 현황(타임라인) → 신메뉴(화면 고정, 포스터 가로 이동) → 메뉴 라인업 → 메뉴 탭 → 원가 문장 → 수익 구조 → 마케팅(화면 고정, 포스터가 날아오름) → 운영 구조(화면 고정, 카드가 겹쳐 쌓임) → 10월 오픈 매장 → 창업 비용 → 절차 → FAQ → 문의

- 움직임은 GSAP 3.12.5와 ScrollTrigger(cdnjs)로 만듭니다. 이 두 파일을 못 불러와도 모든 내용은 정지 상태로 보입니다.
- 로딩 화면은 브라우저 탭마다 처음 한 번만 나옵니다 (1.4~3.2초).
- 오른쪽 섹션 점 내비는 화면 폭 1500px 이상에서만 보입니다. 하단 상담 바는 히어로를 지나면 나타나고 문의 섹션부터 숨습니다.

## 아임웹에 넣는 순서

기존 메인 페이지는 건드리지 않고, 숨김 상태의 새 페이지에 먼저 만듭니다.
아임웹 디자인 모드에는 버전 기록이 없으므로, 큰 변경 전에는 기존 메뉴를 **메뉴 복제**로 백업해 두세요.

1. **새 페이지 만들기**
   디자인 모드 > 메뉴 관리에서 메뉴를 추가합니다 (예: 이름 `가맹안내`, URL `franchise-new`).
   메뉴 설정에서 **메뉴 숨김**을 켭니다. 링크로만 들어갈 수 있는 페이지가 됩니다.

2. **공통 코드 넣기**
   관리자 > 환경설정 > SEO(검색엔진최적화) > 고급 설정 > **공통 코드 삽입**을 켭니다.
   - Header Code: `dist/imweb/00-common-head.html` 내용 전체
   - Footer Code: `dist/imweb/00-common-body.html` 내용 전체

   이미 들어 있는 코드가 있으면 지우지 말고 그 아래에 붙여 넣습니다. 저장합니다.
   스타일은 `.hbd` 안에서만 동작하고, 스크립트는 하복당 본문이 있는 페이지에서만 동작하므로 다른 페이지 모양은 바뀌지 않습니다.

3. **본문 넣기**
   새 페이지에 섹션을 추가하고, 빈 곳을 우클릭해 **섹션 설정**을 엽니다.
   - 가로 100% 확장(전체 너비)
   - 좌우 여백 0, 상하 여백 0
   - 그리드 간격 0

   그 섹션에 **코드 위젯**을 추가하고, `dist/imweb/01-main-widget.html` 내용 전체를 붙여 넣습니다.
   코드 위젯 설정에서 **애니메이션을 '없음'** 으로 둡니다. 위젯 등장 효과가 켜져 있으면 화면 고정 장면이 어긋납니다.

4. **문의 입력폼 넣기**
   본문 섹션 바로 아래에 새 섹션을 추가하고 **입력폼 위젯**을 넣습니다.
   - 섹션 배경색: `#FFF8F0`
   - 입력폼 이름: `하복당 가맹 1:1 미팅 신청`
   - 항목: 이름(필수), 연락처(필수), 희망 지역(선택형: 서울/경기/인천, 필수), 문의 내용
   - 개인정보수집 동의: 켜고 아래 문구를 넣습니다 (보유 기간은 본사가 정해 채움).
     `수집 목적: 가맹 상담 일정 안내 / 항목: 이름, 연락처, 희망 지역, 문의 내용 / 보유 기간: 상담 종료 후 ○개월 / 동의하지 않을 수 있으며, 동의하지 않으면 상담 신청을 할 수 없습니다.`
   - 버튼 문구: `1:1 미팅 신청하기`, 가로 꽉 채움
   - 접수 알림: 이메일 알림 켜기

   페이지의 "미팅 신청" 버튼은 본문 맨 아래 문의 안내(`#hbd-contact`)로 이동하고, 그 바로 아래에 이 입력폼이 보입니다.

5. **미리보기로 확인**
   코드 위젯은 디자인 모드 화면에서는 보이지 않고 **미리보기**에서만 보입니다.
   PC와 모바일 폭에서 다음을 확인합니다.
   - 처음 들어올 때 과일 로딩 화면이 돌고 사라짐
   - 화면 고정 장면 4곳(소자본 창업, 신메뉴, 마케팅, 운영 구조)이 사이트 헤더 아래에서 시작함
   - 메뉴 탭, 숫자 카운트, 하단 상담 바

6. **게시하기**
   아래 "게시 전에 본사가 확인할 것"을 정리한 뒤 **게시하기**를 누릅니다. 메인으로 바꾸려면 메뉴 관리에서 이 메뉴를 맨 위로 옮깁니다.

z-index: 하단 상담 바 1033, 섹션 점 내비 1034, 스크롤 진행 막대 1035입니다. 아임웹 헤더(1000)보다 위, 팝업(1040 이상)보다 아래에 있습니다.

## 게시 전에 본사가 확인할 것

이 페이지는 가맹점 모집 광고라 가맹사업법과 표시광고법이 적용됩니다. 아래는 검수에서 나온 항목이며, 법률 판단은 가맹거래사나 변호사에게 확인하세요.

- **정보공개서 등록**: 2026년 10월 16일 공정위 가맹사업거래 사이트에서 하복당 정보공개서가 검색되지 않았습니다. 등록된 정보공개서를 주고 14일이 지나기 전에는 가맹금을 받거나 계약할 수 없습니다(가맹사업법 제7조). 절차 섹션에 이 단계를 넣어 두었습니다.
- **수익 정보**: 지점 매출·순이익은 1:1 미팅에서 서면으로 주고, 근거 자료(POS, 배달앱 정산서, 매입 계산서)를 본사 사무소에 보관해야 합니다(제9조). 페이지 문구에 이 내용을 넣어 두었습니다.
- **안양점 수치**: 블로그 본문의 순이익 13,806,595원(25.7%)은 점주가 말로 알려준 홀·픽업 매출 300만원이 들어간 값입니다. 페이지에는 블로그 손익표의 10,806,595원(배달 매출 50,732,200원 기준 21.3%)을 썼습니다. 부가세·소득세·점주 인건비 반영 여부가 공개 자료에 없어 "순이익" 대신 "영업잔여금"으로 적었습니다. 홀·픽업 매출 증빙이 있으면 되돌릴 수 있습니다.
- **오픈 매장 목록**: 10월 포스터의 15곳을 그대로 넣었습니다. 목포남악점, 춘천점은 "서울·경기·인천 50호점까지만"과 맞지 않아 모집 지역 문장은 이 목록 옆에서 뺐습니다. 지점마다 "영업 중 / 오픈 예정"과 기준일을 알려 주시면 표시할 수 있습니다. 목포점이 7월 말부터 영업 중이라는 외부 자료도 있어 "10월 오픈"이 맞는지 확인이 필요합니다.
- **산도 메뉴**: 요청하신 6종(모둠·딸기·망고·멜론·오렌지·귤)을 넣었습니다. 본사 광고에는 "생과일 산도 3종"(망고·모둠·멜론)으로 나오므로, 지금 6종 모두 판매하는지 확인하세요.

## 수정하는 방법

1. `src/` 파일을 고칩니다.
2. 커밋하고 푸시합니다.
3. 그 커밋의 SHA로 다시 빌드하고, 바뀐 `dist/imweb/`를 커밋·푸시합니다.
   ```
   python3 site/build.py dist --sha <커밋SHA> --phone 010-7683-1577
   ```
4. 바뀐 `dist/imweb/` 파일을 아임웹에 다시 붙여 넣습니다.

미리보기 파일 만들기 (내 컴퓨터에서 열어 보기):
```
python3 site/build.py preview --mode cdn --sha <커밋SHA> --phone 010-7683-1577 --out preview.html
```

이미지와 CSS, JS는 이 저장소에서 jsDelivr로 불러옵니다.
- 이 저장소를 **비공개로 바꾸면 이미지와 스타일이 깨집니다.**
- 커밋 SHA로 고정한 주소라서 브랜치를 지워도 바로 깨지지는 않지만, 가능하면 브랜치를 유지하세요.
