# 하복당 가맹 페이지 (아임웹용)

요거트월드 가맹 사이트 구성을 참고해 만든 하복당 가맹 모집 페이지입니다.
본문은 아임웹 **코드 위젯 1개**에, 공통 스타일과 스크립트는 **공통 코드 삽입**에 넣습니다.
문의 입력폼, 머리말(헤더), 바닥글은 아임웹 기본 기능을 그대로 씁니다.

## 폴더 구성

| 경로 | 내용 |
| --- | --- |
| `src/sections/*.html` | 섹션별 원본 HTML (16개). `{{IMG}}`는 빌드할 때 이미지 주소로 바뀝니다. |
| `src/hbd.css`, `src/hbd.js` | 공통 스타일·스크립트 원본. 모든 스타일은 `.hbd` 안에만 적용됩니다. |
| `img/` | 웹용으로 줄인 이미지 27장 |
| `dist/hbd.css`, `dist/hbd.js` | 배포용 스타일·스크립트 (jsDelivr로 불러옴) |
| `dist/imweb/00-common-head.html` | 공통 코드 **Header Code**에 붙여 넣을 코드 |
| `dist/imweb/00-common-body.html` | 공통 코드 **Footer Code**에 붙여 넣을 코드 |
| `dist/imweb/01-main-widget.html` | 코드 위젯에 붙여 넣을 페이지 본문 전체 |
| `build.py` | 위 파일들과 미리보기를 만드는 스크립트 |

## 아임웹에 넣는 순서

기존 메인 페이지는 건드리지 않고, 숨김 상태의 새 페이지에 먼저 만듭니다.
아임웹 디자인 모드에는 버전 기록이 없으므로, 큰 변경 전에는 기존 메뉴를 **메뉴 복제**로 백업해 두세요.

1. **새 페이지 만들기**
   디자인 모드 > 메뉴 관리에서 메뉴를 추가합니다 (예: 이름 `가맹안내`, URL `franchise-new`).
   메뉴 설정에서 **메뉴 숨김**을 켭니다. 링크로만 들어갈 수 있는 페이지가 됩니다.

2. **공통 코드 넣기**
   관리자 > 환경설정 > SEO(검색엔진최적화) > 고급 설정 > **공통 코드 삽입**을 켭니다.
   - Header Code: `dist/imweb/00-common-head.html` 내용 전체
   - Footer Code: `dist/imweb/00-common-body.html` 내용 전체

   저장합니다. 모든 스타일은 `.hbd` 안에서만 동작하므로 기존 페이지에는 영향이 없습니다.

3. **본문 넣기**
   새 페이지에 섹션을 추가하고, 빈 곳을 우클릭해 **섹션 설정**을 엽니다.
   - 가로 100% 확장(전체 너비)
   - 좌우 여백 0, 상하 여백 0
   - 그리드 간격 0

   그 섹션에 **코드 위젯**을 추가하고, `dist/imweb/01-main-widget.html` 내용 전체를 붙여 넣습니다.

4. **문의 입력폼 넣기**
   본문 섹션 바로 아래에 새 섹션을 추가하고 **입력폼 위젯**을 넣습니다.
   - 섹션 배경색: `#FFF8F0`
   - 입력폼 이름: `하복당 가맹 1:1 미팅 신청`
   - 항목: 이름(필수), 연락처(필수), 희망 지역(선택형: 서울/경기/인천, 필수), 문의 내용
   - 개인정보수집 동의: 켜기
   - 버튼 문구: `1:1 미팅 신청하기`, 가로 꽉 채움
   - 접수 알림: 이메일 알림 켜기

   페이지의 "미팅 신청" 버튼은 본문 맨 아래 문의 안내(`#hbd-contact`)로 이동하고, 그 바로 아래에 이 입력폼이 보입니다.

5. **미리보기로 확인**
   코드 위젯은 디자인 모드 화면에서는 보이지 않고 **미리보기**에서만 보입니다.
   PC와 모바일 폭에서 탭, 숫자 카운트, 하단 상담 바가 동작하는지 확인합니다.

6. **게시하기**
   확인이 끝나면 **게시하기**를 누릅니다. 메인으로 바꾸려면 메뉴 관리에서 이 메뉴를 맨 위로 옮깁니다.

## 수정하는 방법

1. `src/` 파일을 고칩니다.
2. 커밋하고 푸시합니다.
3. 그 커밋의 SHA로 다시 빌드합니다.
   ```
   python3 site/build.py dist --sha <커밋SHA> --phone 010-7683-1577
   ```
4. 바뀐 `dist/imweb/` 파일을 아임웹에 다시 붙여 넣습니다.

이미지와 CSS, JS는 이 저장소에서 jsDelivr로 불러옵니다.
- 이 저장소를 **비공개로 바꾸면 이미지와 스타일이 깨집니다.**
- 커밋 SHA로 고정한 주소라서 브랜치를 지워도 바로 깨지지는 않지만, 가능하면 브랜치를 유지하세요.
