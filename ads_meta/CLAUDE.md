# 하복당 메타 광고 소재 — 상시 규칙 (사용자 지시)

## 사이즈 변경 (리사이즈)
- 사이즈를 바꿀 때는 **텍스트도 항상 캔버스에 맞춰 같이 키우거나 줄인다** (2026-11-10 지시).
  - 배율 = √(새 면적 ÷ 원본 면적). 1:1→9:16 = 1.33배, 4:5→9:16 = 1.19배, 4:5→1:1 = 0.89배.
  - 글자 크기, 패딩, 로고, 버튼, 그림자까지 같은 배율로 키우거나 줄인다.
  - 좌우 여백 65px를 넘는 줄은 글자를 줄이지 말고 자연스러운 위치에서 줄을 바꾼다.
    - 예: "월매출 / 8200만원?", "300만원 / 부터?!".
  - 10% 이내로만 넘치면 그만큼 줄여 폭에 맞춰도 된다.
  - 렌더링 후 `measure.js`로 텍스트 범위를 측정해 원본 대비 배율을 확인한다.
- 그 외 디자인(문구, 색, 사진, 요소)은 그대로 둔다. 요소를 새로 추가하거나 빼지 않는다.
- 메타 9:16 안전영역:
  - 릴스: 핵심 문구와 로고를 y 269–1248, 좌우 65px 안에 둔다.
  - 스토리: y 269–1651 안에 둔다.

## 문구
- 소재를 전달할 때는 **항상 메타 광고 문구도 같이 적는다**: 제목, 설명, 기본 문구.
- 매출 수치는 근거(매장·기간·집계 방법)가 필요하다. 근거는 기본 문구에 적는다.
- 비용 수치(300만원, 2500만원, 3천만원)는 포함 범위를 밝혀 서로 모순되지 않게 한다.
- 이미지 하단의 작은 흰색 각주는 넣지 않는다. 사용자가 반복해서 지웠다.

## 사진
- 하복당 쪽은 실사 사진만 쓴다. AI로 만든 배경(커피→과일 합성 등)은 사용자가 거절했다.
- 저장소가 공개 저장소이므로 사람이 찍힌 사진과 그 렌더는 커밋하지 않는다(.gitignore). `assets/real_empty_cafe.jpg`와 `sw3_*` 출력물이 여기에 해당한다.
